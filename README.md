# MMDVM Dashboard

**MMDVM Dashboard by IV3SCP**

A web dashboard for monitoring MMDVM digital voice repeater systems.

## Features

- Real-time repeater status and activity.
- Service monitoring for MMDVMHost, DMRGateway, YSFGateway, DStarGateway, M17Gateway and APRSGateway.
- Recent DMR activity and QSO history.
- Configurable service links.
- Repeater information and system status.
- Web interface with a dark theme.

## Project

Developed for the IR3ZZO repeater site, operated by A.R.I. Gorizia.

Created by **IV3SCP**.
